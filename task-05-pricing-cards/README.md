# Task 05 — Pricing Cards

## Scenario
A SaaS pricing page needs to show 3 pricing tiers side by side, with the recommended plan visually standing out from the rest.

## Task
Using **Flexbox**, lay out `.pricing-row` so the `.pricing-card` items sit in a row. Emphasize the `.featured` card (e.g. with `flex-grow` and/or `transform: scale`) so it stands out, and make sure the row wraps onto multiple lines on narrow screens instead of squishing.

## Acceptance Criteria
- Layout built with Flexbox (no floats, no absolute positioning)
- The `.featured` card is visually emphasized compared to the others
- Cards wrap gracefully at narrow widths
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Card background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text: `#4b5563`
- Border: `#e5e7eb`
- Accent/button (featured card): `#2563eb`
