# Task 03 — Sidebar Layout

## Scenario
Admin panels and dashboard apps typically use a fixed-width navigation sidebar next to a main content area that takes up the rest of the screen.

## Task
Using **Flexbox**, lay out `.app-shell` so `.sidebar` stays a fixed width and `.main-content` flexes to fill the remaining horizontal space.

## Acceptance Criteria
- Layout built with Flexbox (no floats, no absolute positioning)
- Sidebar has a fixed width and does not shrink or grow
- Main content fills all remaining space
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Sidebar/card background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text/border: `#d1d5db`
- Dark text accent: `#111827`
