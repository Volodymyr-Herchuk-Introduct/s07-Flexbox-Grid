# S07 — Flexbox and CSS Grid

8 real-life UI layout tasks — build each one to match the provided mockup.

For most tasks the technique (Flexbox or Grid) is specified, but part of the exercise is learning to recognize which tool fits which layout problem — pay attention to *why* each layout was built the way it was, not just how.

## Tasks
Do the Flexbox tasks (1, 3, 5, 6) after the Flexbox lesson, the Grid tasks (2, 4, 8) after the CSS Grid lesson, and task 7 last.

1. [Navbar](task-01-navbar/README.md) — Flexbox
2. [Product Grid](task-02-product-grid/README.md) — Grid
3. [Sidebar Layout](task-03-sidebar-layout/README.md) — Flexbox
4. [Dashboard (Unequal Panels)](task-04-dashboard-unequal/README.md) — Grid
5. [Pricing Cards](task-05-pricing-cards/README.md) — Flexbox
6. [Media Object](task-06-media-object/README.md) — Flexbox
7. [Holy Grail Layout](task-07-holy-grail/README.md) — you decide
8. [Photo Gallery](task-08-gallery/README.md) — Grid

## Submitting
1. Open the starter repository on GitHub and click **Use this template → Create a new repository** to get your own copy.
2. Clone your repository and do the task.
3. Commit your changes with clear messages and push them to GitHub.
4. Submit the link to your repository in Moodle.
