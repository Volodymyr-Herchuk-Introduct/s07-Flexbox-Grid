# Task 06 — Media Object

## Scenario
Comment threads and notification lists repeat the same pattern over and over: a small avatar next to a block of text — the classic "media object".

## Task
Using **Flexbox**, lay out each `.comment` so the `.avatar` has a fixed width and the `.comment-body` flexes to fill the rest of the row.

## Acceptance Criteria
- Layout built with Flexbox (no floats, no absolute positioning)
- Avatar stays a fixed width and does not shrink
- Comment body fills the remaining space and text wraps naturally
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Comment background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text: `#4b5563`
- Border: `#e5e7eb`
- Avatar accent: `#818cf8` / `#a5b4fc`
