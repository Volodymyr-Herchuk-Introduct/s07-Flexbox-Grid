# Task 08 — Photo Gallery

## Scenario
A photo gallery page needs a grid of images where most cells are the same size, but a couple of standout photos take up extra space to break up the monotony.

## Task
Using **CSS Grid**, lay out `.gallery` as an even grid of equal-size `.gallery-item` cells. Make the `.wide` item span 2 columns (`grid-column: span 2`) and the `.tall` item span 2 rows (`grid-row: span 2`).

## Acceptance Criteria
- Layout built with CSS Grid (no floats, no absolute positioning)
- Most cells are equal size; `.wide` and `.tall` items visibly span extra columns/rows
- Grid stays intact and readable at narrow widths
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Gallery/card background: `#ffffff`
- Text: `#1a1a1a`
- Border: `#e5e7eb`

Note: gallery tile colors are placeholder images — tile background color doesn't need to match exactly.
