# Task 01 — Navbar

## Scenario
Every site needs a header navigation bar: logo on one side, links on the other, and it must not break on mobile.

## Task
Using **Flexbox**, lay out `.site-header` so the `.logo` sits on the left and `.nav` links are pushed to the right. Add `flex-wrap` so the links drop to a second line on narrow screens instead of overflowing or squishing.

## Acceptance Criteria
- Layout built with Flexbox (no floats, no absolute positioning)
- Logo left-aligned, nav links right-aligned
- Nav links wrap gracefully at narrow widths (test at least 2 breakpoints in DevTools)
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Header/card background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text/border: `#d1d5db`
- Dark text accent: `#111827`
