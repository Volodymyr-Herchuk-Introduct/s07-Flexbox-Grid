# Task 07 — Holy Grail Layout

## Scenario
A classic content site needs a full-width header and footer, with a three-column body in between: a navigation column, a main content column, and a sidebar column.

## Task
Lay out `.page-layout` so `.site-header` and `.site-footer` span the full width, and `.side-nav` / `.content` / `.sidebar` form a three-column row between them, with `.side-nav` and `.sidebar` at a fixed width and `.content` filling the rest. This time, **you decide which technique to use** — think about how many rows and columns you need to control simultaneously before picking flex or grid.

## Acceptance Criteria
- Header and footer span the full width of the layout
- Nav and sidebar columns stay a fixed width; content fills the remaining space
- The chosen technique is used correctly and consistently (no floats, no absolute positioning)
- Matches the mockup provided by the instructor

## Palette
- Background: `#f3f4f6`
- Header/footer/content background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text: `#374151`
- Muted text: `#6b7280` / `#9ca3af`
- Dark text accent: `#111827`
