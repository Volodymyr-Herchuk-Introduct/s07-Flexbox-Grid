# Task 04 — Dashboard (Unequal Panels)

## Scenario
An analytics dashboard needs one large chart panel alongside several smaller stat tiles of different sizes, arranged in a deliberate grid — not a uniform table.

## Task
Using **CSS Grid** and `grid-template-areas`, lay out `.dashboard` so `.chart-panel` occupies a large area and the `.stat-tile` panels fill the remaining smaller areas around it.

## Acceptance Criteria
- Layout built with CSS Grid using named `grid-template-areas`
- Chart panel is visibly larger than the stat tiles
- Stat tiles are unequal in size/position, not a uniform repeating grid
- Matches the mockup provided by the instructor

## Palette
- Background: `#f7f7f8`
- Panel/tile background: `#ffffff`
- Text: `#1a1a1a`
- Secondary text: `#6b7280`
- Border: `#e5e7eb`
- Accent (chart): `#93c5fd` / `#bfdbfe`
